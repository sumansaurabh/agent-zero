## നിങ്ങളോടൊപ്പം വളരുകയും പഠിക്കുകയും ചെയ്യുന്ന ഒരു വ്യക്തിഗത, ഓർഗാനിക് ഏജന്റിക് ചട്ടക്കൂട്

- ഏജന്റ് സീറോ ഒരു മുൻകൂട്ടി നിശ്ചയിച്ച ഏജന്റിക് ചട്ടക്കൂടല്ല. നിങ്ങൾ ഇത് ഉപയോഗിക്കുമ്പോൾ ചലനാത്മകമായി, സ്വാഭാവികമായി വളരാനും പഠിക്കാനും ഇത് രൂപകൽപ്പന ചെയ്തിരിക്കുന്നു.
- ഏജന്റ് സീറോ പൂർണ്ണമായും സുതാര്യവും, വായിക്കാൻ കഴിയുന്നതും, മനസ്സിലാക്കാവുന്നതും, ഇഷ്ടാനുസൃതമാക്കാവുന്നതും, സംവേദനാത്മകവുമാണ്.
- ഏജന്റ് സീറോ അതിന്റെ (നിങ്ങളുടെ) ജോലികൾ പൂർത്തിയാക്കാൻ കമ്പ്യൂട്ടറിനെ ഒരു ഉപകരണമായി ഉപയോഗിക്കുന്നു.

# 💡 പ്രധാന സവിശേഷതകൾ

1. **പൊതുവായ ആവശ്യങ്ങൾക്കുള്ള അസിസ്റ്റന്റ്**

- ഏജന്റ് സീറോ പ്രത്യേക ജോലികൾക്കായി മുൻകൂട്ടി പ്രോഗ്രാം ചെയ്തിട്ടില്ല (എന്നാൽ അങ്ങനെയാകാം). ഇത് ഒരു പൊതുവായ ആവശ്യങ്ങൾക്കുള്ള വ്യക്തിഗത അസിസ്റ്റന്റായി ഉദ്ദേശിച്ചുള്ളതാണ്. ഇതിന് ഒരു ടാസ്ക് നൽകുക, അത് വിവരങ്ങൾ ശേഖരിക്കുകയും, കമാൻഡുകളും കോഡുകളും എക്സിക്യൂട്ട് ചെയ്യുകയും, മറ്റ് ഏജന്റ് ഇൻസ്റ്റൻസുകളുമായി സഹകരിക്കുകയും, അത് പൂർത്തിയാക്കാൻ പരമാവധി ശ്രമിക്കുകയും ചെയ്യും.
- ഇതിന് സ്ഥിരമായ മെമ്മറിയുണ്ട്, ഇത് മുൻകാല പരിഹാരങ്ങൾ, കോഡുകൾ, വസ്തുതകൾ, നിർദ്ദേശങ്ങൾ മുതലായവ ഓർമ്മിക്കാൻ അനുവദിക്കുന്നു, ഭാവിയിൽ ജോലികൾ വേഗത്തിലും കൂടുതൽ വിശ്വസനീയമായും പരിഹരിക്കാൻ ഇത് സഹായിക്കുന്നു.

![Agent 0 Working](/docs/res/ui-screen-2.png)

2. **കമ്പ്യൂട്ടർ ഒരു ഉപകരണമായി**

- ഏജന്റ് സീറോ അതിന്റെ ജോലികൾ പൂർത്തിയാക്കാൻ ഓപ്പറേറ്റിംഗ് സിസ്റ്റത്തെ ഒരു ഉപകരണമായി ഉപയോഗിക്കുന്നു. ഇതിന് മുൻകൂട്ടി പ്രോഗ്രാം ചെയ്ത ഒറ്റ-ഉദ്ദേശ്യ ഉപകരണങ്ങളില്ല. പകരം, അതിന് സ്വന്തമായി കോഡ് എഴുതാനും ടെർമിനൽ ഉപയോഗിച്ച് സ്വന്തമായി ഉപകരണങ്ങൾ ആവശ്യമനുസരിച്ച് സൃഷ്ടിക്കാനും ഉപയോഗിക്കാനും കഴിയും.
- അതിന്റെ ആയുധപ്പുരയിലെ ഏക ഡിഫോൾട്ട് ടൂളുകൾ ഓൺലൈൻ തിരയൽ, മെമ്മറി സവിശേഷതകൾ, ആശയവിനിമയം (ഉപയോക്താവുമായും മറ്റ് ഏജന്റുമാരുമായും), കോഡ്/ടെർമിനൽ എക്സിക്യൂഷൻ എന്നിവയാണ്. മറ്റെല്ലാം ഏജന്റ് സ്വയം സൃഷ്ടിച്ചതോ ഉപയോക്താവിന് വികസിപ്പിക്കാൻ കഴിയുന്നതോ ആണ്.
- വളരെ ചെറിയ മോഡലുകളിൽ പോലും ഏറ്റവും അനുയോജ്യവും വിശ്വസനീയവുമാകാൻ ടൂൾ ഉപയോഗിക്കാനുള്ള കഴിവ് ആദ്യം മുതൽ വികസിപ്പിച്ചെടുത്തിട്ടുണ്ട്.
- **ഡിഫോൾട്ട് ടൂളുകൾ:** ഏജന്റ് സീറോയിൽ അറിവ്, വെബ്പേജ് ഉള്ളടക്കം, കോഡ് എക്സിക്യൂഷൻ, ആശയവിനിമയം തുടങ്ങിയ ടൂളുകൾ ഉൾപ്പെടുന്നു.
- **കസ്റ്റം ടൂളുകൾ സൃഷ്ടിക്കുന്നു:** നിങ്ങളുടെ സ്വന്തം കസ്റ്റം ടൂളുകൾ സൃഷ്ടിച്ച് ഏജന്റ് സീറോയുടെ പ്രവർത്തനം വികസിപ്പിക്കുക.
- **ഇൻസ്ട്രുമെന്റുകൾ:** ഏജന്റ് സീറോയ്ക്ക് വിളിക്കാൻ കഴിയുന്ന കസ്റ്റം ഫംഗ്ഷനുകളും നടപടിക്രമങ്ങളും സൃഷ്ടിക്കാൻ നിങ്ങളെ അനുവദിക്കുന്ന ഒരു പുതിയ തരം ഉപകരണങ്ങളാണ് ഇൻസ്ട്രുമെന്റുകൾ.

3. **മൾട്ടി-ഏജന്റ് സഹകരണം**

- ഓരോ ഏജന്റിനും അതിന് ജോലികളും നിർദ്ദേശങ്ങളും നൽകുന്ന ഒരു മേലുദ്യോഗസ്ഥനുണ്ട്. ഓരോ ഏജന്റും അതിന്റെ മേലുദ്യോഗസ്ഥന് റിപ്പോർട്ട് ചെയ്യുന്നു.
- ശൃംഖലയിലെ ആദ്യത്തെ ഏജന്റിന്റെ (ഏജന്റ് 0) കാര്യത്തിൽ, മേലുദ്യോഗസ്ഥൻ മനുഷ്യ ഉപയോക്താവാണ്; ഏജന്റ് ഒരു വ്യത്യാസവും കാണുന്നില്ല.
- ഓരോ ഏജന്റിനും ഉപജോലികൾ വിഭജിക്കാനും പരിഹരിക്കാനും സഹായിക്കുന്നതിന് അതിന്റെ കീഴ്വഴക്കമുള്ള ഏജന്റിനെ സൃഷ്ടിക്കാൻ കഴിയും. ഇത് എല്ലാ ഏജന്റുമാർക്കും അവരുടെ സന്ദർഭം വൃത്തിയായി സൂക്ഷിക്കാനും ശ്രദ്ധ കേന്ദ്രീകരിക്കാനും സഹായിക്കുന്നു.

4. **പൂർണ്ണമായും ഇഷ്ടാനുസൃതമാക്കാവുന്നതും വികസിപ്പിക്കാവുന്നതും**

- ഈ ചട്ടക്കൂടിൽ ഒന്നും തന്നെ ഹാർഡ്-കോഡ് ചെയ്തിട്ടില്ല. ഒന്നും മറച്ചുവെച്ചിട്ടില്ല. എല്ലാം ഉപയോക്താവിന് വികസിപ്പിക്കാനോ മാറ്റാനോ കഴിയും.
- **prompts/default/agent.system.md** ഫയലിലെ ഒരു സിസ്റ്റം പ്രോംപ്റ്റ് വഴിയാണ് മുഴുവൻ സ്വഭാവവും നിർവചിച്ചിരിക്കുന്നത്. ഈ പ്രോംപ്റ്റ് മാറ്റുക, ചട്ടക്കൂട് നാടകീയമായി മാറും.
- ചട്ടക്കൂട് ഏജന്റിനെ ഒരു തരത്തിലും നയിക്കുകയോ പരിമിതപ്പെടുത്തുകയോ ചെയ്യുന്നില്ല. ഏജന്റുമാർക്ക് പിന്തുടരേണ്ട ഹാർഡ്-കോഡ് ചെയ്ത റെയിലുകളൊന്നുമില്ല.
- ഓരോ പ്രോംപ്റ്റും, അതിന്റെ ആശയവിനിമയ ലൂപ്പിൽ ഏജന്റിന് അയച്ച ഓരോ ചെറിയ സന്ദേശ ടെംപ്ലേറ്റും **prompts/** ഫോൾഡറിൽ കണ്ടെത്താനും മാറ്റാനും കഴിയും.
- ഓരോ ഡിഫോൾട്ട് ടൂളും **python/tools/** ഫോൾഡറിൽ കണ്ടെത്താനും മാറ്റാനോ പുതിയ മുൻകൂട്ടി നിശ്ചയിച്ച ടൂളുകൾ സൃഷ്ടിക്കാൻ പകർത്താനോ കഴിയും.

5. **ആശയവിനിമയം പ്രധാനം**

- നിങ്ങളുടെ ഏജന്റിന് ശരിയായ സിസ്റ്റം പ്രോംപ്റ്റും നിർദ്ദേശങ്ങളും നൽകുക, അതിന് അത്ഭുതങ്ങൾ ചെയ്യാൻ കഴിയും.
- ഏജന്റുമാർക്ക് അവരുടെ മേലുദ്യോഗസ്ഥരുമായും കീഴ്വഴക്കമുള്ളവരുമായും ആശയവിനിമയം നടത്താൻ കഴിയും, ചോദ്യങ്ങൾ ചോദിക്കാനും നിർദ്ദേശങ്ങൾ നൽകാനും മാർഗ്ഗനിർദ്ദേശം നൽകാനും കഴിയും. ഫലപ്രദമായി ആശയവിനിമയം നടത്താൻ നിങ്ങളുടെ ഏജന്റുമാരെ സിസ്റ്റം പ്രോംപ്റ്റിൽ നിർദ്ദേശിക്കുക.
- ടെർമിനൽ ഇന്റർഫേസ് തത്സമയം സ്ട്രീം ചെയ്യുകയും സംവേദനാത്മകവുമാണ്. നിങ്ങൾക്ക് ഏത് ഘട്ടത്തിലും നിർത്താനും ഇടപെടാനും കഴിയും. നിങ്ങളുടെ ഏജന്റ് തെറ്റായ ദിശയിലേക്ക് പോകുന്നത് കണ്ടാൽ, ഉടൻ തന്നെ നിർത്തി അതിനോട് പറയുക.
- ഈ ചട്ടക്കൂടിൽ ധാരാളം സ്വാതന്ത്ര്യമുണ്ട്. തുടരാൻ അനുവാദം ചോദിച്ച് മേലുദ്യോഗസ്ഥർക്ക് പതിവായി റിപ്പോർട്ട് ചെയ്യാൻ നിങ്ങളുടെ ഏജന്റുമാരെ നിർദ്ദേശിക്കാം. ഉപജോലികൾ ഏൽപ്പിക്കേണ്ടത് എപ്പോഴാണെന്ന് തീരുമാനിക്കുമ്പോൾ പോയിന്റ് സ്കോറിംഗ് സിസ്റ്റങ്ങൾ ഉപയോഗിക്കാൻ നിങ്ങൾക്ക് അവരെ നിർദ്ദേശിക്കാം. മേലുദ്യോഗസ്ഥർക്ക് കീഴ്വഴക്കമുള്ളവരുടെ ഫലങ്ങൾ വീണ്ടും പരിശോധിക്കാനും തർക്കിക്കാനും കഴിയും. സാധ്യതകൾ അനന്തമാണ്.

## 🚀 ഏജന്റ് സീറോ ഉപയോഗിച്ച് നിങ്ങൾക്ക് നിർമ്മിക്കാൻ കഴിയുന്ന കാര്യങ്ങൾ

- **വികസന പ്രോജക്റ്റുകൾ** - `"തത്സമയ ഡാറ്റാ വിഷ്വലൈസേഷനോടുകൂടിയ ഒരു റിയാക്റ്റ് ഡാഷ്ബോർഡ് സൃഷ്ടിക്കുക"`

- **ഡാറ്റാ വിശകലനം** - `"കഴിഞ്ഞ പാദത്തിലെ NVIDIA വിൽപ്പന ഡാറ്റ വിശകലനം ചെയ്യുകയും ട്രെൻഡ് റിപ്പോർട്ടുകൾ സൃഷ്ടിക്കുകയും ചെയ്യുക"`

- **ഉള്ളടക്കം സൃഷ്ടിക്കൽ** - `"മൈക്രോസർവീസുകളെക്കുറിച്ച് ഒരു സാങ്കേതിക ബ്ലോഗ് പോസ്റ്റ് എഴുതുക"`

- **സിസ്റ്റം അഡ്മിൻ** - `"ഞങ്ങളുടെ വെബ് സെർവറുകൾക്കായി ഒരു മോണിറ്ററിംഗ് സിസ്റ്റം സജ്ജീകരിക്കുക"`

- **ഗവേഷണം** - `"CoT പ്രോംപ്റ്റിംഗിനെക്കുറിച്ചുള്ള അഞ്ച് സമീപകാല AI പേപ്പറുകൾ ശേഖരിച്ച് സംഗ്രഹിക്കുക"`

# ⚙️ ഇൻസ്റ്റാളേഷൻ

ഏജന്റ് സീറോ എങ്ങനെ ഇൻസ്റ്റാൾ ചെയ്യാമെന്ന് പഠിക്കാൻ വീഡിയോ തുറക്കാൻ ക്ലിക്ക് ചെയ്യുക:

[![Testing Video](/docs/res/new_vid.jpg)](https://www.youtube.com/watch?v=cHDCCSr1YRI&t=24s)

വിൻഡോസ്, മാക്ഒഎസ്, ലിനക്സ് എന്നിവയ്ക്കുള്ള വിശദമായ സജ്ജീകരണ ഗൈഡ് വീഡിയോയോടൊപ്പം ഏജന്റ് സീറോ ഡോക്യുമെന്റേഷനിൽ [ഈ പേജിൽ](./docs/installation.md) കാണാം.

### ⚡ പെട്ടെന്നുള്ള തുടക്കം

```bash
# ഡോക്കർ ഉപയോഗിച്ച് പുൾ ചെയ്ത് പ്രവർത്തിപ്പിക്കുക

docker pull frdel/agent-zero-run
docker run -p 50001:80 frdel/agent-zero-run

# ആരംഭിക്കാൻ http://localhost:50001 സന്ദർശിക്കുക
```

- ഡെവലപ്പർമാർക്കും സംഭാവന ചെയ്യുന്നവർക്കും: നിങ്ങളുടെ സിസ്റ്റത്തിനായുള്ള പൂർണ്ണ ബൈനറികൾ [റിലീസ് പേജിൽ](https://github.com/frdel/agent-zero/releases) നിന്ന് ഡൗൺലോഡ് ചെയ്യുക, തുടർന്ന് [ഇവിടെ നൽകിയിട്ടുള്ള](./docs/installation.md#in-depth-guide-for-full-binaries-installation) നിർദ്ദേശങ്ങൾ പാലിക്കുക.

## 🐳 പൂർണ്ണമായും ഡോക്കറൈസ് ചെയ്തത്, സ്പീച്ച്-ടു-ടെക്സ്റ്റ്, ടിടിഎസ് എന്നിവയോടൊപ്പം

![Settings](docs/res/settings-page-ui.png)

- ഇഷ്ടാനുസൃതമാക്കാവുന്ന ക്രമീകരണങ്ങൾ ഉപയോക്താക്കൾക്ക് ഏജന്റിന്റെ സ്വഭാവവും പ്രതികരണങ്ങളും അവരുടെ ആവശ്യങ്ങൾക്കനുസരിച്ച് ക്രമീകരിക്കാൻ അനുവദിക്കുന്നു.
- വെബ് യുഐ ഔട്ട്പുട്ട് വളരെ വൃത്തിയുള്ളതും, ദ്രാവകവും, വർണ്ണാഭമായതും, വായിക്കാൻ കഴിയുന്നതും, സംവേദനാത്മകവുമാണ്; ഒന്നും മറച്ചുവെച്ചിട്ടില്ല.
- നിങ്ങൾക്ക് വെബ് യുഐയിൽ നേരിട്ട് ചാറ്റുകൾ ലോഡ് ചെയ്യാനോ സംരക്ഷിക്കാനോ കഴിയും.
- ടെർമിനലിൽ നിങ്ങൾ കാണുന്ന അതേ ഔട്ട്പുട്ട് ഓരോ സെഷനും **logs/** ഫോൾഡറിലെ ഒരു HTML ഫയലിലേക്ക് സ്വയമേവ സംരക്ഷിക്കപ്പെടുന്നു.

![Time example](/docs/res/time_example.jpg)

- ഏജന്റ് ഔട്ട്പുട്ട് തത്സമയം സ്ട്രീം ചെയ്യപ്പെടുന്നു, ഇത് ഉപയോക്താക്കൾക്ക് വായിക്കാനും ഏത് സമയത്തും ഇടപെടാനും അനുവദിക്കുന്നു.
- കോഡിംഗ് ആവശ്യമില്ല; പ്രോംപ്റ്റിംഗും ആശയവിനിമയ കഴിവുകളും മാത്രം മതി.
- ഒരു മികച്ച സിസ്റ്റം പ്രോംപ്റ്റ് ഉപയോഗിച്ച്, ചെറിയ മോഡലുകളിൽ പോലും, കൃത്യമായ ടൂൾ ഉപയോഗം ഉൾപ്പെടെ, ചട്ടക്കൂട് വിശ്വസനീയമാണ്.

## 👀 ശ്രദ്ധിക്കുക

1. **ഏജന്റ് സീറോ അപകടകരമായേക്കാം!**

- ശരിയായ നിർദ്ദേശങ്ങളോടെ, ഏജന്റ് സീറോയ്ക്ക് നിങ്ങളുടെ കമ്പ്യൂട്ടർ, ഡാറ്റ അല്ലെങ്കിൽ അക്കൗണ്ടുകൾ എന്നിവയുമായി ബന്ധപ്പെട്ട് അപകടകരമായേക്കാവുന്ന പല കാര്യങ്ങളും ചെയ്യാൻ കഴിയും. എല്ലായ്പ്പോഴും ഏജന്റ് സീറോ ഒരു ഒറ്റപ്പെട്ട ചുറ്റുപാടിൽ (ഡോക്കർ പോലെ) പ്രവർത്തിപ്പിക്കുക, നിങ്ങൾ എന്താണ് ആഗ്രഹിക്കുന്നതെന്ന് ശ്രദ്ധിക്കുക.

2. **ഏജന്റ് സീറോ പ്രോംപ്റ്റ് അടിസ്ഥാനമാക്കിയുള്ളതാണ്.**

- മുഴുവൻ ചട്ടക്കൂടും **prompts/** ഫോൾഡർ വഴിയാണ് നയിക്കപ്പെടുന്നത്. ഏജന്റ് മാർഗ്ഗനിർദ്ദേശങ്ങൾ, ടൂൾ നിർദ്ദേശങ്ങൾ, സന്ദേശങ്ങൾ, യൂട്ടിലിറ്റി AI ഫംഗ്ഷനുകൾ, എല്ലാം അവിടെയുണ്ട്.
