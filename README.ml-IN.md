## നിങ്ങളോടൊപ്പം വളരുകയും പഠിക്കുകയും ചെയ്യുന്ന ഒരു വ്യക്തിഗത, ഓർഗാനിക് ഏജൻ്റിക് ഫ്രെയിംവർക്ക്

- Agent Zero മുൻകൂട്ടി നിർവചിച്ച ഒരു ഏജൻ്റിക് ഫ്രെയിംവർക്കല്ല. ഇത് നിങ്ങൾ ഉപയോഗിക്കുന്നതിനനുസരിച്ച് ചലനാത്മകമായും സ്വാഭാവികമായും വളരുകയും പഠിക്കുകയും ചെയ്യുന്ന രീതിയിൽ രൂപകൽപ്പന ചെയ്തിട്ടുള്ളതാണ്.
- Agent Zero പൂർണ്ണമായും സുതാര്യവും, വായിക്കാൻ എളുപ്പമുള്ളതും, മനസ്സിലാക്കാൻ കഴിയുന്നതും, ഇഷ്ടാനുസൃതമാക്കാവുന്നതും, സംവേദനാത്മകവുമാണ്.
- Agent Zero കമ്പ്യൂട്ടറിനെ അതിൻ്റെ (നിങ്ങളുടെ) ടാസ്ക്കുകൾ പൂർത്തിയാക്കുന്നതിനുള്ള ഒരു ഉപകരണമായി ഉപയോഗിക്കുന്നു.

# 💡 പ്രധാന സവിശേഷതകൾ

1. **പൊതു ആവശ്യങ്ങൾക്കുള്ള സഹായി**

- Agent Zero നിർദ്ദിഷ്ട ജോലികൾക്കായി മുൻകൂട്ടി പ്രോഗ്രാം ചെയ്തിട്ടില്ല (എന്നാൽ ചെയ്യാൻ കഴിയും). ഇത് ഒരു പൊതു ആവശ്യങ്ങൾക്കുള്ള വ്യക്തിഗത സഹായിയായി ഉദ്ദേശിച്ചിട്ടുള്ളതാണ്. ഇതിന് ഒരു ടാസ്ക് നൽകുക, അത് വിവരങ്ങൾ ശേഖരിക്കുകയും, കമാൻഡുകളും കോഡുകളും എക്സിക്യൂട്ട് ചെയ്യുകയും, മറ്റ് ഏജൻ്റ് ഇൻസ്റ്റൻസുകളുമായി സഹകരിക്കുകയും, അത് പൂർത്തിയാക്കാൻ പരമാവധി ശ്രമിക്കുകയും ചെയ്യും.
- ഇതിന് ഒരു സ്ഥിരമായ മെമ്മറി ഉണ്ട്, ഇത് മുൻകാല പരിഹാരങ്ങൾ, കോഡ്, വസ്തുതകൾ, നിർദ്ദേശങ്ങൾ മുതലായവ ഓർമ്മിക്കാൻ സഹായിക്കുന്നു, അതുവഴി ഭാവിയിൽ ജോലികൾ വേഗത്തിലും കൂടുതൽ വിശ്വാസ്യതയോടെയും പരിഹരിക്കാൻ കഴിയും.

![Agent 0 Working](/docs/res/ui-screen-2.png)

2. **ഒരു ഉപകരണമായി കമ്പ്യൂട്ടർ**

- Agent Zero അതിൻ്റെ ജോലികൾ പൂർത്തിയാക്കാൻ ഓപ്പറേറ്റിംഗ് സിസ്റ്റത്തെ ഒരു ഉപകരണമായി ഉപയോഗിക്കുന്നു. ഇതിന് മുൻകൂട്ടി പ്രോഗ്രാം ചെയ്ത ഒറ്റ-ഉദ്ദേശ്യ ടൂളുകൾ ഇല്ല. പകരം, അതിന് അതിൻ്റേതായ കോഡ് എഴുതാനും, ടെർമിനൽ ഉപയോഗിച്ച് അതിൻ്റേതായ ടൂളുകൾ ആവശ്യത്തിനനുസരിച്ച് സൃഷ്ടിക്കാനും ഉപയോഗിക്കാനും കഴിയും.
- ഇതിൻ്റെ ആഴ്സനലിലെ ഏക ഡിഫോൾട്ട് ടൂളുകൾ ഓൺലൈൻ തിരയൽ, മെമ്മറി ഫീച്ചറുകൾ, ആശയവിനിമയം (ഉപയോക്താവുമായും മറ്റ് ഏജൻ്റുമാരുമായും), കോഡ്/ടെർമിനൽ എക്സിക്യൂഷൻ എന്നിവയാണ്. മറ്റെല്ലാം ഏജൻ്റ് സ്വയം സൃഷ്ടിക്കുന്നതാണ് അല്ലെങ്കിൽ ഉപയോക്താവിന് വികസിപ്പിക്കാവുന്നതാണ്.
- വളരെ ചെറിയ മോഡലുകളിൽ പോലും, ടൂൾ ഉപയോഗിക്കാനുള്ള പ്രവർത്തനം ഏറ്റവും അനുയോജ്യവും വിശ്വസനീയവുമാക്കാൻ ആദ്യം മുതൽ വികസിപ്പിച്ചെടുത്തിട്ടുണ്ട്.
- **സ്ഥിരസ്ഥിതി ടൂളുകൾ:** Agent Zero-യിൽ അറിവ്, വെബ് പേജ് ഉള്ളടക്കം, കോഡ് എക്സിക്യൂഷൻ, ആശയവിനിമയം തുടങ്ങിയ ടൂളുകൾ ഉൾപ്പെടുന്നു.
- **കസ്റ്റം ടൂളുകൾ സൃഷ്ടിക്കൽ:** നിങ്ങളുടെ സ്വന്തം കസ്റ്റം ടൂളുകൾ സൃഷ്ടിച്ച് Agent Zero-യുടെ പ്രവർത്തനക്ഷമത വർദ്ധിപ്പിക്കുക.
- **ഇൻസ്ട്രുമെൻ്റ്സ്:** Agent Zero-ക്ക് വിളിക്കാൻ കഴിയുന്ന കസ്റ്റം ഫംഗ്ഷനുകളും പ്രൊസീജറുകളും സൃഷ്ടിക്കാൻ നിങ്ങളെ അനുവദിക്കുന്ന ഒരു പുതിയ തരം ടൂളാണ് ഇൻസ്ട്രുമെൻ്റ്സ്.

3. **മൾട്ടി-ഏജൻ്റ് സഹകരണം**

- ഓരോ ഏജൻ്റിനും ടാസ്ക്കുകളും നിർദ്ദേശങ്ങളും നൽകുന്ന ഒരു മികച്ച ഏജൻ്റ് ഉണ്ട്. ഓരോ ഏജൻ്റും പിന്നീട് അതിൻ്റെ മികച്ച ഏജൻ്റിന് റിപ്പോർട്ട് ചെയ്യുന്നു.
- ശൃംഖലയിലെ ആദ്യ ഏജൻ്റിൻ്റെ (Agent 0) കാര്യത്തിൽ, മികച്ച ഏജൻ്റ് മനുഷ്യ ഉപയോക്താവാണ്; ഏജൻ്റ് ഒരു വ്യത്യാസവും കാണുന്നില്ല.
- ഓരോ ഏജൻ്റിനും ഉപടാസ്ക്കുകൾ വിഭജിച്ച് പരിഹരിക്കാൻ സഹായിക്കുന്നതിന് അതിൻ്റെ കീഴ്ജീവനക്കാരനായ ഏജൻ്റിനെ സൃഷ്ടിക്കാൻ കഴിയും. ഇത് എല്ലാ ഏജൻ്റുമാർക്കും അവരുടെ സന്ദർഭം വ്യക്തവും കേന്ദ്രീകൃതവുമായി നിലനിർത്താൻ സഹായിക്കുന്നു.

4. **പൂർണ്ണമായും ഇഷ്ടാനുസൃതമാക്കാവുന്നതും വികസിപ്പിക്കാവുന്നതും**

- ഈ ഫ്രെയിംവർക്കിൽ ഒന്നും ഹാർഡ് കോഡ് ചെയ്തിട്ടില്ല. ഒന്നും മറച്ചിട്ടില്ല. എല്ലാം ഉപയോക്താവിന് വികസിപ്പിക്കാനോ മാറ്റാനോ കഴിയും.
- മുഴുവൻ സ്വഭാവവും **prompts/default/agent.system.md** ഫയലിലെ ഒരു സിസ്റ്റം പ്രോംപ്റ്റ് വഴിയാണ് നിർവചിച്ചിരിക്കുന്നത്. ഈ പ്രോംപ്റ്റ് മാറ്റിയാൽ ഫ്രെയിംവർക്ക് വലിയ തോതിൽ മാറും.
- ഫ്രെയിംവർക്ക് ഏജൻ്റിനെ ഒരു തരത്തിലും നയിക്കുകയോ പരിമിതപ്പെടുത്തുകയോ ചെയ്യുന്നില്ല. ഏജൻ്റുമാർക്ക് പിന്തുടരേണ്ട ഹാർഡ് കോഡ് ചെയ്ത റെയിലുകൾ ഇല്ല.
- ഏജൻ്റുമായി അതിൻ്റെ ആശയവിനിമയ ലൂപ്പിൽ അയക്കുന്ന ഓരോ പ്രോംപ്റ്റും, ഓരോ ചെറിയ സന്ദേശ ടെംപ്ലേറ്റും **prompts/** ഫോൾഡറിൽ കണ്ടെത്താനും മാറ്റാനും കഴിയും.
- ഓരോ സ്ഥിരസ്ഥിതി ടൂളും **python/tools/** ഫോൾഡറിൽ കണ്ടെത്താനും മാറ്റാനോ അല്ലെങ്കിൽ പുതിയ മുൻനിർവചിത ടൂളുകൾ സൃഷ്ടിക്കാൻ പകർത്തി ഉപയോഗിക്കാനോ കഴിയും.

5. **ആശയവിനിമയം പ്രധാനം**

- നിങ്ങളുടെ ഏജൻ്റിന് ശരിയായ സിസ്റ്റം പ്രോംപ്റ്റും നിർദ്ദേശങ്ങളും നൽകുക, അത് അത്ഭുതങ്ങൾ ചെയ്യാൻ കഴിയും.
- ഏജൻ്റുമാർക്ക് അവരുടെ ഉന്നതരുമായും കീഴ്ജീവനക്കാരുമായും ആശയവിനിമയം നടത്താൻ കഴിയും, ചോദ്യങ്ങൾ ചോദിക്കാനും നിർദ്ദേശങ്ങൾ നൽകാനും മാർഗ്ഗനിർദ്ദേശം നൽകാനും. സിസ്റ്റം പ്രോംപ്റ്റിൽ നിങ്ങളുടെ ഏജൻ്റുമാർക്ക് എങ്ങനെ ഫലപ്രദമായി ആശയവിനിമയം നടത്തണമെന്ന് നിർദ്ദേശിക്കുക.
- ടെർമിനൽ ഇൻ്റർഫേസ് തത്സമയം സ്ട്രീം ചെയ്യുകയും സംവേദനാത്മകവുമാണ്. നിങ്ങൾക്ക് എപ്പോൾ വേണമെങ്കിലും നിർത്താനും ഇടപെടാനും കഴിയും. നിങ്ങളുടെ ഏജൻ്റ് തെറ്റായ ദിശയിലേക്ക് പോകുന്നത് കണ്ടാൽ, ഉടൻ തന്നെ നിർത്തി അത് പറയുക.
- ഈ ചട്ടക്കൂടിൽ വളരെയധികം സ്വാതന്ത്ര്യമുണ്ട്. തുടരാൻ അനുമതി ചോദിച്ച് നിങ്ങളുടെ ഏജൻ്റുമാരോട് പതിവായി മേലുദ്യോഗസ്ഥർക്ക് റിപ്പോർട്ട് ചെയ്യാൻ നിങ്ങൾക്ക് നിർദ്ദേശിക്കാം. ഉപജോലികൾ ഏൽപ്പിക്കേണ്ടിവരുമ്പോൾ പോയിൻ്റ് സ്കോറിംഗ് സംവിധാനങ്ങൾ ഉപയോഗിക്കാൻ നിങ്ങൾക്ക് അവരോട് നിർദ്ദേശിക്കാം. മേലുദ്യോഗസ്ഥർക്ക് കീഴ്ജീവനക്കാരുടെ ഫലങ്ങൾ വീണ്ടും പരിശോധിക്കാനും തർക്കിക്കാനും കഴിയും. സാധ്യതകൾ അനന്തമാണ്.

## 🚀 Agent Zero ഉപയോഗിച്ച് നിങ്ങൾക്ക് നിർമ്മിക്കാൻ കഴിയുന്ന കാര്യങ്ങൾ

- **ഡാറ്റാ വിശകലനം** - `"കഴിഞ്ഞ പാദത്തിലെ NVIDIA വിൽപ്പന ഡാറ്റ വിശകലനം ചെയ്യുകയും ട്രെൻഡ് റിപ്പോർട്ടുകൾ സൃഷ്ടിക്കുകയും ചെയ്യുക"`

- **ഉള്ളടക്ക സൃഷ്ടി** - `"മൈക്രോസർവീസുകളെക്കുറിച്ച് ഒരു സാങ്കേതിക ബ്ലോഗ് പോസ്റ്റ് എഴുതുക"`

- **സിസ്റ്റം അഡ്മിൻ** - `"ഞങ്ങളുടെ വെബ് സെർവറുകൾക്കായി ഒരു മോണിറ്ററിംഗ് സിസ്റ്റം സജ്ജമാക്കുക"`

- **ഗവേഷണം** - `"CoT പ്രോംപ്റ്റിംഗിനെക്കുറിച്ചുള്ള ഏറ്റവും പുതിയ അഞ്ച് AI പേപ്പറുകൾ ശേഖരിച്ച് സംഗ്രഹിക്കുക"`

# ⚙️ ഇൻസ്റ്റാളേഷൻ

Agent Zero എങ്ങനെ ഇൻസ്റ്റാൾ ചെയ്യണമെന്ന് അറിയാൻ ഒരു വീഡിയോ തുറക്കാൻ ക്ലിക്ക് ചെയ്യുക:

[![Testing Video](/docs/res/new_vid.jpg)](https://www.youtube.com/watch?v=cHDCCSr1YRI&t=24s)

Windows, macOS, Linux എന്നിവയ്‌ക്കായുള്ള വിശദമായ സജ്ജീകരണ ഗൈഡ് (ഒരു വീഡിയോ സഹിതം) Agent Zero ഡോക്യുമെൻ്റേഷനിലെ [ഈ പേജിൽ](./docs/installation.md) കണ്ടെത്താനാകും.

### ⚡ ദ്രുത ആരംഭം

```bash
# Docker ഉപയോഗിച്ച് വലിച്ചിടുകയും പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുക

docker pull frdel/agent-zero-run
docker run -p 50001:80 frdel/agent-zero-run

# ആരംഭിക്കാൻ http://localhost:50001 സന്ദർശിക്കുക
```

- ഡെവലപ്പർമാരും സംഭാവന ചെയ്യുന്നവരും: [റിലീസ് പേജിൽ](https://github.com/frdel/agent-zero/releases) നിന്ന് നിങ്ങളുടെ സിസ്റ്റത്തിനായുള്ള പൂർണ്ണ ബൈനറികൾ ഡൗൺലോഡ് ചെയ്യുക, തുടർന്ന് [ഇവിടെ നൽകിയിട്ടുള്ള](./docs/installation.md#in-depth-guide-for-full-binaries-installation) നിർദ്ദേശങ്ങൾ പാലിക്കുക.

## 🐳 പൂർണ്ണമായും ഡോക്കറൈസ് ചെയ്തത്, സ്പീച്ച്-ടു-ടെക്സ്റ്റ്, TTS എന്നിവയോടൊപ്പം

![Settings](docs/res/settings-page-ui.png)

- ഇഷ്ടാനുസൃതമാക്കാവുന്ന ക്രമീകരണങ്ങൾ ഉപയോക്താക്കൾക്ക് ഏജൻ്റിൻ്റെ സ്വഭാവവും പ്രതികരണങ്ങളും അവരുടെ ആവശ്യങ്ങൾക്കനുസരിച്ച് ക്രമീകരിക്കാൻ അനുവദിക്കുന്നു.
- വെബ് UI ഔട്ട്പുട്ട് വളരെ വൃത്തിയുള്ളതും, സുഗമവും, വർണ്ണാഭവുമായ, വായിക്കാൻ എളുപ്പമുള്ളതും, സംവേദനാത്മകവുമാണ്; ഒന്നും മറഞ്ഞിരിക്കുന്നില്ല.
- വെബ് UI-യിൽ നേരിട്ട് ചാറ്റുകൾ ലോഡ് ചെയ്യാനോ സംരക്ഷിക്കാനോ നിങ്ങൾക്ക് കഴിയും.
- ടെർമിനലിൽ നിങ്ങൾ കാണുന്ന അതേ ഔട്ട്പുട്ട് ഓരോ സെഷനും **logs/** ഫോൾഡറിലെ ഒരു HTML ഫയലിൽ സ്വയമേവ സംരക്ഷിക്കപ്പെടും.

![Time example](/docs/res/time_example.jpg)

- ഏജൻ്റ് ഔട്ട്പുട്ട് തത്സമയം സ്ട്രീം ചെയ്യുന്നു, ഇത് ഉപയോക്താക്കൾക്ക് എപ്പോൾ വേണമെങ്കിലും വായിക്കാനും ഇടപെടാനും അനുവദിക്കുന്നു.
- കോഡിംഗ് ആവശ്യമില്ല; പ്രോംപ്റ്റിംഗും ആശയവിനിമയ കഴിവുകളും മാത്രം മതി.
- ഒരു ശക്തമായ സിസ്റ്റം പ്രോംപ്റ്റ് ഉപയോഗിച്ച്, ചെറിയ മോഡലുകളിൽ പോലും, കൃത്യമായ ടൂൾ ഉപയോഗം ഉൾപ്പെടെ, ഫ്രെയിംവർക്ക് വിശ്വസനീയമാണ്.

## 👀 ശ്രദ്ധിക്കുക

1. **Agent Zero അപകടകരമായേക്കാം!**

- ശരിയായ നിർദ്ദേശങ്ങളോടെ, Agent Zero-ന് നിങ്ങളുടെ കമ്പ്യൂട്ടർ, ഡാറ്റ, അല്ലെങ്കിൽ അക്കൗണ്ടുകൾ എന്നിവയുമായി ബന്ധപ്പെട്ട് അപകടകരമായേക്കാവുന്ന പല കാര്യങ്ങളും ചെയ്യാൻ കഴിയും. Agent Zero എല്ലായ്പ്പോഴും ഒരു ഒറ്റപ്പെട്ട ചുറ്റുപാടിൽ (Docker പോലുള്ളവ) പ്രവർത്തിപ്പിക്കുകയും നിങ്ങളുടെ ആഗ്രഹങ്ങളെക്കുറിച്ച് ശ്രദ്ധയോടെയിരിക്കുകയും ചെയ്യുക.

2. **Agent Zero പ്രോംപ്റ്റ് അടിസ്ഥാനമാക്കിയുള്ളതാണ്.**

- മുഴുവൻ ഫ്രെയിംവർക്കും **prompts/** ഫോൾഡർ വഴിയാണ് നയിക്കപ്പെടുന്നത്. ഏജൻ്റ് മാർഗ്ഗനിർദ്ദേശങ്ങൾ, ടൂൾ നിർദ്ദേശങ്ങൾ, സന്ദേശങ്ങൾ, യൂട്ടിലിറ്റി AI ഫംഗ്ഷനുകൾ, എല്ലാം അവിടെയുണ്ട്.
