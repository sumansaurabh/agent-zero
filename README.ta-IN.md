- Agent Zero என்பது முன் வரையறுக்கப்பட்ட முகவர் கட்டமைப்பு அல்ல. இது நீங்கள் பயன்படுத்தும்போது மாறும், இயற்கையாக வளரும் மற்றும் கற்றுக்கொள்ளும் வகையில் வடிவமைக்கப்பட்டுள்ளது.
- Agent Zero முழுமையாக வெளிப்படையானது, படிக்கக்கூடியது, புரிந்துகொள்ளக்கூடியது, தனிப்பயனாக்கக்கூடியது மற்றும் ஊடாடும் தன்மை கொண்டது.
- Agent Zero அதன் (உங்கள்) பணிகளைச் செய்ய கணினியை ஒரு கருவியாகப் பயன்படுத்துகிறது.

# 💡 முக்கிய அம்சங்கள்

1. **பொது நோக்கத்திற்கான உதவியாளர்**

- Agent Zero குறிப்பிட்ட பணிகளுக்காக முன் திட்டமிடப்படவில்லை (ஆனால் அவ்வாறு இருக்கலாம்). இது ஒரு பொது நோக்கத்திற்கான தனிப்பட்ட உதவியாளராக இருக்க வேண்டும். இதற்கு ஒரு பணியைக் கொடுங்கள், அது தகவல்களைச் சேகரிக்கும், கட்டளைகள் மற்றும் குறியீடுகளைச் செயல்படுத்தும், பிற முகவர் நிகழ்வுகளுடன் ஒத்துழைக்கும், மேலும் அதைச் செய்ய தன்னால் முடிந்ததைச் செய்யும்.
- இது ஒரு நிரந்தர நினைவகத்தைக் கொண்டுள்ளது, இது முந்தைய தீர்வுகள், குறியீடுகள், உண்மைகள், வழிமுறைகள் போன்றவற்றை நினைவில் வைத்து, எதிர்காலத்தில் பணிகளை விரைவாகவும் நம்பகத்தன்மையுடனும் தீர்க்க அனுமதிக்கிறது.

2. **கணினி ஒரு கருவியாக**

- Agent Zero அதன் பணிகளைச் செய்ய இயக்க முறைமையை ஒரு கருவியாகப் பயன்படுத்துகிறது. இதற்கு ஒற்றை நோக்கத்திற்கான கருவிகள் முன் திட்டமிடப்படவில்லை. அதற்கு பதிலாக, அது தனது சொந்த குறியீட்டை எழுதலாம் மற்றும் தேவைக்கேற்ப தனது சொந்த கருவிகளை உருவாக்க மற்றும் பயன்படுத்த டெர்மினலைப் பயன்படுத்தலாம்.
- அதன் ஆயுதக் களஞ்சியத்தில் உள்ள ஒரே இயல்புநிலை கருவிகள் ஆன்லைன் தேடல், நினைவக அம்சங்கள், தொடர்பு (பயனர் மற்றும் பிற முகவர்களுடன்), மற்றும் குறியீடு/டெர்மினல் செயல்படுத்துதல். மற்ற அனைத்தும் முகவரால் உருவாக்கப்படுகின்றன அல்லது பயனரால் நீட்டிக்கப்படலாம்.
- கருவி பயன்பாட்டு செயல்பாடு மிகச் சிறிய மாடல்களுடன் கூட மிகவும் இணக்கமானதாகவும் நம்பகமானதாகவும் இருக்க புதிதாக உருவாக்கப்பட்டுள்ளது.
- **இயல்புநிலை கருவிகள்:** Agent Zero அறிவு, வலைப்பக்க உள்ளடக்கம், குறியீடு செயல்படுத்துதல் மற்றும் தொடர்பு போன்ற கருவிகளை உள்ளடக்கியது.
- **தனிப்பயன் கருவிகளை உருவாக்குதல்:** உங்கள் சொந்த தனிப்பயன் கருவிகளை உருவாக்குவதன் மூலம் Agent Zero இன் செயல்பாட்டை நீட்டிக்கவும்.
- **கருவிகள் (Instruments):** கருவிகள் (Instruments) என்பது ஒரு புதிய வகை கருவியாகும், இது Agent Zero ஆல் அழைக்கப்படக்கூடிய தனிப்பயன் செயல்பாடுகள் மற்றும் நடைமுறைகளை உருவாக்க உங்களை அனுமதிக்கிறது.

- உங்கள் முகவருக்கு சரியான சிஸ்டம் ப்ராம்ட் மற்றும் வழிமுறைகளை வழங்குங்கள், அது அற்புதங்களைச் செய்ய முடியும்.

- **ஆராய்ச்சி** - `"CoT ப்ராம்ட்டிங் பற்றிய ஐந்து சமீபத்திய AI கட்டுரைகளைச் சேகரித்து சுருக்கவும்"`

# ⚙️ நிறுவுதல்

Agent Zero ஐ எவ்வாறு நிறுவுவது என்பதை அறிய வீடியோவைத் திறக்க கிளிக் செய்யவும்:

[![Testing Video](/docs/res/new_vid.jpg)](https://www.youtube.com/watch?v=cHDCCSr1YRI&t=24s)

Windows, macOS மற்றும் Linux க்கான விரிவான அமைவு வழிகாட்டி ஒரு வீடியோவுடன் Agent Zero ஆவணத்தில் [இந்த பக்கத்தில்](./docs/installation.md) காணலாம்.

### ⚡ விரைவு தொடக்கம்

```bash
# Docker உடன் இழுத்து இயக்கவும்

docker pull frdel/agent-zero-run
docker run -p 50001:80 frdel/agent-zero-run

# தொடங்க http://localhost:50001 ஐப் பார்வையிடவும்
```

- டெவலப்பர்கள் மற்றும் பங்களிப்பாளர்கள்: உங்கள் கணினிக்கான முழு பைனரிகளை [வெளியீடுகள் பக்கத்திலிருந்து](https://github.com/frdel/agent-zero/releases) பதிவிறக்கம் செய்து, பின்னர் [இங்கு வழங்கப்பட்டுள்ள வழிமுறைகளைப்](./docs/installation.md#in-depth-guide-for-full-binaries-installation) பின்பற்றவும்.

## 🐳 முழுமையாக Dockerized, பேச்சு-க்கு-உரை மற்றும் TTS உடன்

![Settings](docs/res/settings-page-ui.png)

- தனிப்பயனாக்கக்கூடிய அமைப்புகள் பயனர்கள் முகவரின் நடத்தை மற்றும் பதில்களை அவர்களின் தேவைகளுக்கு ஏற்ப மாற்ற அனுமதிக்கின்றன.
- வலை UI வெளியீடு மிகவும் சுத்தமானது, திரவமானது, வண்ணமயமானது, படிக்கக்கூடியது மற்றும் ஊடாடும் தன்மை கொண்டது; எதுவும் மறைக்கப்படவில்லை.
- வலை UI க்குள் நேரடியாக அரட்டைகளை ஏற்றலாம் அல்லது சேமிக்கலாம்.
- டெர்மினலில் நீங்கள் காணும் அதே வெளியீடு ஒவ்வொரு அமர்வுக்கும் **logs/** கோப்புறையில் ஒரு HTML கோப்பில் தானாகவே சேமிக்கப்படும்.

![Time example](/docs/res/time_example.jpg)

- முகவர் வெளியீடு நிகழ்நேரத்தில் ஸ்ட்ரீம் செய்யப்படுகிறது, இது பயனர்கள் எந்த நேரத்திலும் படித்து தலையிட அனுமதிக்கிறது.
- குறியீட்டு முறை தேவையில்லை; ப்ராம்ட்டிங் மற்றும் தொடர்பு திறன்கள் மட்டுமே அவசியம்.
- ஒரு திடமான சிஸ்டம் ப்ராம்ட் மூலம், சிறிய மாடல்களுடன் கூட, துல்லியமான கருவி பயன்பாடு உட்பட, கட்டமைப்பு நம்பகமானது.

## 👀 நினைவில் கொள்ளுங்கள்

1. **Agent Zero ஆபத்தானதாக இருக்கலாம்!**

- சரியான அறிவுறுத்தலுடன், Agent Zero பல விஷயங்களைச் செய்யக்கூடியது, உங்கள் கணினி, தரவு அல்லது கணக்குகள் தொடர்பான ஆபத்தான செயல்களையும் கூட. Agent Zero ஐ எப்போதும் ஒரு தனிமைப்படுத்தப்பட்ட சூழலில் (Docker போன்றவை) இயக்கவும் மற்றும் நீங்கள் விரும்புவதில் கவனமாக இருங்கள்.

2. **Agent Zero ப்ராம்ட் அடிப்படையிலானது.**

- முழு கட்டமைப்பும் **prompts/** கோப்புறையால் வழிநடத்தப்படுகிறது. முகவர் வழிகாட்டுதல்கள், கருவி வழிமுறைகள், செய்திகள், பயன்பாட்டு AI செயல்பாடுகள், அனைத்தும் அங்கு உள்ளன.
