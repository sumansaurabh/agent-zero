## একটি ব্যক্তিগত, জৈব এজেন্টিক ফ্রেমওয়ার্ক যা আপনার সাথে বৃদ্ধি পায় এবং শেখে

- Agent Zero একটি পূর্বনির্ধারিত এজেন্টিক ফ্রেমওয়ার্ক নয়। এটি গতিশীল, জৈবভাবে বৃদ্ধিশীল এবং আপনি এটি ব্যবহার করার সাথে সাথে শেখার জন্য ডিজাইন করা হয়েছে।
- Agent Zero সম্পূর্ণ স্বচ্ছ, পাঠযোগ্য, বোধগম্য, কাস্টমাইজযোগ্য এবং ইন্টারঅ্যাক্টিভ।
- Agent Zero তার (আপনার) কাজগুলি সম্পন্ন করার জন্য কম্পিউটারকে একটি টুল হিসাবে ব্যবহার করে।

# 💡 মূল বৈশিষ্ট্যসমূহ

1. **সাধারণ-উদ্দেশ্য সহায়ক**

- Agent Zero নির্দিষ্ট কাজের জন্য পূর্ব-প্রোগ্রাম করা নয় (তবে হতে পারে)। এটি একটি সাধারণ-উদ্দেশ্য ব্যক্তিগত সহায়ক হওয়ার জন্য তৈরি। এটিকে একটি কাজ দিন, এবং এটি তথ্য সংগ্রহ করবে, কমান্ড এবং কোড চালাবে, অন্যান্য এজেন্ট ইনস্ট্যান্সের সাথে সহযোগিতা করবে এবং এটি সম্পন্ন করার জন্য যথাসাধ্য চেষ্টা করবে।
- এটির একটি স্থায়ী মেমরি রয়েছে, যা এটিকে ভবিষ্যতে দ্রুত এবং আরও নির্ভরযোগ্যভাবে কাজগুলি সমাধান করার জন্য পূর্ববর্তী সমাধান, কোড, তথ্য, নির্দেশাবলী ইত্যাদি মনে রাখতে দেয়।

![Agent 0 Working](/docs/res/ui-screen-2.png)

2. **টুল হিসাবে কম্পিউটার**

- Agent Zero তার কাজগুলি সম্পন্ন করার জন্য অপারেটিং সিস্টেমকে একটি টুল হিসাবে ব্যবহার করে। এটির কোনো একক-উদ্দেশ্য টুল পূর্ব-প্রোগ্রাম করা নেই। পরিবর্তে, এটি প্রয়োজন অনুযায়ী নিজস্ব কোড লিখতে এবং টার্মিনাল ব্যবহার করে নিজস্ব টুল তৈরি এবং ব্যবহার করতে পারে।
- এর অস্ত্রাগারে একমাত্র ডিফল্ট টুলগুলি হল অনলাইন অনুসন্ধান, মেমরি বৈশিষ্ট্য, যোগাযোগ (ব্যবহারকারী এবং অন্যান্য এজেন্টদের সাথে), এবং কোড/টার্মিনাল এক্সিকিউশন। বাকি সবকিছু এজেন্ট নিজেই তৈরি করে বা ব্যবহারকারী দ্বারা প্রসারিত করা যেতে পারে।
- টুল ব্যবহারের কার্যকারিতা সবচেয়ে সামঞ্জস্যপূর্ণ এবং নির্ভরযোগ্য হওয়ার জন্য শুরু থেকে তৈরি করা হয়েছে, এমনকি খুব ছোট মডেলের সাথেও।
- **ডিফল্ট টুলস:** Agent Zero-এ জ্ঞান, ওয়েবপেজ কন্টেন্ট, কোড এক্সিকিউশন এবং যোগাযোগের মতো টুল রয়েছে।
- **কাস্টম টুল তৈরি করা:** আপনার নিজস্ব কাস্টম টুল তৈরি করে Agent Zero-এর কার্যকারিতা প্রসারিত করুন।
- **ইন্সট্রুমেন্টস:** ইন্সট্রুমেন্টস হল একটি নতুন ধরনের টুল যা আপনাকে কাস্টম ফাংশন এবং প্রসিডিউর তৈরি করতে দেয় যা Agent Zero দ্বারা কল করা যেতে পারে।

3. **মাল্টি-এজেন্ট সহযোগিতা**

- প্রতিটি এজেন্টের একটি উচ্চতর এজেন্ট রয়েছে যা এটিকে কাজ এবং নির্দেশাবলী দেয়। প্রতিটি এজেন্ট তারপর তার উচ্চতরকে রিপোর্ট করে।
- চেইনের প্রথম এজেন্টের ক্ষেত্রে (Agent 0), উচ্চতর হল মানব ব্যবহারকারী; এজেন্ট কোনো পার্থক্য দেখে না।
- প্রতিটি এজেন্ট উপকাজগুলি ভাঙতে এবং সমাধান করতে সাহায্য করার জন্য তার অধস্তন এজেন্ট তৈরি করতে পারে। এটি সমস্ত এজেন্টকে তাদের প্রসঙ্গ পরিষ্কার এবং ফোকাসড রাখতে সাহায্য করে।

4. **সম্পূর্ণ কাস্টমাইজযোগ্য এবং প্রসারণযোগ্য**

- এই ফ্রেমওয়ার্কে প্রায় কিছুই হার্ড-কোডেড নয়। কিছুই লুকানো নেই। সবকিছু ব্যবহারকারী দ্বারা প্রসারিত বা পরিবর্তন করা যেতে পারে।
- সম্পূর্ণ আচরণ **prompts/default/agent.system.md** ফাইলে একটি সিস্টেম প্রম্পট দ্বারা সংজ্ঞায়িত করা হয়। এই প্রম্পট পরিবর্তন করুন এবং ফ্রেমওয়ার্ককে নাটকীয়ভাবে পরিবর্তন করুন।
- ফ্রেমওয়ার্ক কোনোভাবে এজেন্টকে গাইড বা সীমাবদ্ধ করে না। এজেন্টদের অনুসরণ করতে হবে এমন কোনো হার্ড-কোডেড রেল নেই।
- প্রতিটি প্রম্পট, প্রতিটি ছোট বার্তা টেমপ্লেট যা এজেন্টকে তার যোগাযোগ লুপে পাঠানো হয় তা **prompts/** ফোল্ডারে পাওয়া যাবে এবং পরিবর্তন করা যাবে।
- প্রতিটি ডিফল্ট টুল **python/tools/** ফোল্ডারে পাওয়া যাবে এবং নতুন পূর্বনির্ধারিত টুল তৈরি করতে পরিবর্তন বা কপি করা যাবে।

![Prompts](/docs/res/prompts.png)

5. **যোগাযোগই মূল চাবিকাঠি**

- আপনার এজেন্টকে একটি সঠিক সিস্টেম প্রম্পট এবং নির্দেশাবলী দিন, এবং এটি অলৌকিক কাজ করতে পারে।
- এজেন্টরা তাদের উচ্চতর এবং অধস্তনদের সাথে যোগাযোগ করতে পারে, প্রশ্ন জিজ্ঞাসা করতে, নির্দেশাবলী দিতে এবং নির্দেশনা প্রদান করতে পারে। কার্যকরভাবে যোগাযোগ করার জন্য সিস্টেম প্রম্পটে আপনার এজেন্টদের নির্দেশ দিন।
- টার্মিনাল ইন্টারফেস রিয়েল-টাইম স্ট্রিম করা এবং ইন্টারঅ্যাক্টিভ। আপনি যেকোনো সময় থামতে এবং হস্তক্ষেপ করতে পারেন। আপনি যদি দেখেন যে আপনার এজেন্ট ভুল দিকে যাচ্ছে, তাহলে থামুন এবং এটিকে সাথে সাথে বলুন।
- এই ফ্রেমওয়ার্কে অনেক স্বাধীনতা রয়েছে। আপনি আপনার এজেন্টদের নিয়মিত উচ্চতরদের কাছে রিপোর্ট করতে এবং চালিয়ে যাওয়ার অনুমতি চাইতে নির্দেশ দিতে পারেন। আপনি তাদের উপকাজ অর্পণ করার সিদ্ধান্ত নেওয়ার সময় পয়েন্ট-স্কোরিং সিস্টেম ব্যবহার করতে নির্দেশ দিতে পারেন। উচ্চতররা অধস্তনদের ফলাফল দুবার পরীক্ষা করতে এবং বিতর্ক করতে পারে। সম্ভাবনা অসীম।

# ⚙️ ইনস্টলেশন

Agent Zero কীভাবে ইনস্টল করবেন তা শিখতে একটি ভিডিও খুলতে ক্লিক করুন:

[![Testing Video](/docs/res/new_vid.jpg)](https://www.youtube.com/watch?v=cHDCCSr1YRI&t=24s)

Windows, macOS এবং Linux-এর জন্য একটি ভিডিও সহ বিস্তারিত সেটআপ গাইড Agent Zero ডকুমেন্টেশনে [এই পৃষ্ঠায়](./docs/installation.md) পাওয়া যাবে।

### ⚡ দ্রুত শুরু

```bash
# Docker দিয়ে Pull এবং Run করুন

docker pull frdel/agent-zero-run
docker run -p 50001:80 frdel/agent-zero-run

# শুরু করতে http://localhost:50001 ভিজিট করুন
```

- ডেভেলপার এবং অবদানকারীরা: [রিলিজ পৃষ্ঠা](https://github.com/frdel/agent-zero/releases) থেকে আপনার সিস্টেমের জন্য সম্পূর্ণ বাইনারি ডাউনলোড করুন এবং তারপর [এখানে প্রদত্ত নির্দেশাবলী](./docs/installation.md#in-depth-guide-for-full-binaries-installation) অনুসরণ করুন।

- কাস্টমাইজযোগ্য সেটিংস ব্যবহারকারীদের তাদের প্রয়োজন অনুযায়ী এজেন্টের আচরণ এবং প্রতিক্রিয়া তৈরি করতে দেয়।
- Web UI আউটপুট খুবই পরিষ্কার, তরল, রঙিন, পাঠযোগ্য এবং ইন্টারঅ্যাক্টিভ; কিছুই লুকানো নেই।
- আপনি সরাসরি Web UI-এর মধ্যে চ্যাট লোড বা সংরক্ষণ করতে পারেন।
- টার্মিনালে আপনি যে আউটপুট দেখেন তা স্বয়ংক্রিয়ভাবে প্রতিটি সেশনের জন্য **logs/** ফোল্ডারে একটি HTML ফাইলে সংরক্ষিত হয়।

![Time example](/docs/res/time_example.jpg)

- এজেন্ট আউটপুট রিয়েল-টাইমে স্ট্রিম করা হয়, যা ব্যবহারকারীদের পড়তে এবং যেকোনো সময় হস্তক্ষেপ করতে দেয়।
- কোনো কোডিং প্রয়োজন নেই; শুধুমাত্র প্রম্পটিং এবং যোগাযোগ দক্ষতা প্রয়োজন।
- একটি শক্ত সিস্টেম প্রম্পট সহ, ফ্রেমওয়ার্কটি ছোট মডেলের সাথেও নির্ভরযোগ্য, সুনির্দিষ্ট টুল ব্যবহার সহ।

## 👀 মনে রাখবেন

1. **Agent Zero বিপজ্জনক হতে পারে!**

- সঠিক নির্দেশাবলী সহ, Agent Zero অনেক কিছু করতে সক্ষম, এমনকি আপনার কম্পিউটার, ডেটা বা অ্যাকাউন্ট সম্পর্কিত সম্ভাব্য বিপজ্জনক কাজও। সর্বদা একটি বিচ্ছিন্ন পরিবেশে (যেমন Docker) Agent Zero চালান এবং আপনি কী চান তা সাবধানে বিবেচনা করুন।

2. **Agent Zero প্রম্পট-ভিত্তিক।**

- সম্পূর্ণ ফ্রেমওয়ার্ক **prompts/** ফোল্ডার দ্বারা পরিচালিত হয়। এজেন্ট নির্দেশিকা, টুল নির্দেশাবলী, বার্তা, ইউটিলিটি AI ফাংশন, সবকিছু সেখানে আছে।
